# API чтения: «голые» ресурсы, мета-эндпоинт `/api/config` и полная сетка слотов с флагом `available`

Контракт чтения — `GET /api/config`, `/api/event-types`,
`/api/event-types/:id/slots?date=…`, `/api/bookings` — держится на нескольких
кросс-эндпоинтных соглашениях, у каждого были настоящие альтернативы.

- **Успешный ответ — «голый» ресурс**: объект для единичного, массив для
  коллекции, поля `camelCase`, без обёртки `{ data }` / `{ items, total }`.
  Обёртка `{ error }` (ADR-0005) появляется только на ошибке.
- **Префикс `/api`** совпадает с прокси Vite; версионирования нет.
- **Мета-эндпоинт `GET /api/config`** отдаёт зону сервиса, рабочее окно, длину
  окна записи и `today`. Фронт не выводит окна сам — они конфигурируются на
  бекенде через env (ADR-0004, #14), — а узнаёт их из ответа; иначе экран записи
  и форма создания типа разошлись бы с фактическим конфигом.
- **Слоты — полная сетка дня с булевым `available`**, а не только свободные:
  занятые и уже начавшиеся слоты показываются, но помечаются недоступными.
  `available` = нет пересечения с бронью, а для сегодняшнего дня — ещё и
  `start > now`. Момент отдаётся как ISO 8601 со смещением зоны сервиса
  (ADR-0004).
- **«Предстоящая» встреча = `end > now`**: идущий прямо сейчас звонок остаётся
  в списке до завершения; окно записи дополнительно не фильтруется.

## Considered Options

- **Обёртка `{ data }` / `{ items, total }`** — отброшена: пагинации нет, обёртка
  добавляет уровень без пользы.
- **Клиентский вывод окон** (фронт сам знает «14 дней» и «09:00–18:00») —
  отброшен: окна env-конфигурируемы на бекенде, фронт разошёлся бы с ними.
- **Метаданные в ответе `GET /api/event-types`** — отброшены: смешение
  справочника типов событий и конфигурации сервиса.
- **Только свободные слоты в выдаче** — отброшено: контракт обязан показывать и
  занятость, иначе UI не отрисует неактивные слоты.
- **Различать «занят бронью» и «уже начался»** — отброшено: UI обрабатывает их
  одинаково неактивными, отдельное поле контракта лишнее.
- **«Предстоящая» как `start > now`** — отброшено для списка встреч: текущий
  звонок исчезал бы из `/admin` в момент начала.

## Consequences

- Карта ошибок чтения: `400 VALIDATION_ERROR` (+`fields` по имени параметра),
  `400 DATE_OUT_OF_WINDOW`, `404 EVENT_TYPE_NOT_FOUND`, `404 NOT_FOUND`,
  `500 INTERNAL_ERROR` — всё в конверте ADR-0005. Дополняет ADR-0005, который
  фиксировал только `400` и `409`.
- Точные русские тексты `message` не пиннятся: контракт и тесты бьют по `code`.
- Канонический вид контракта — TypeSpec (ADR-0008); `.tsp` пишется при
  реализации, а резолюция живёт в эпике #2 разделом «HTTP API».

# Доступность и адаптивность: WCAG 2.2 AA, axe + ручной чеклист, mobile-first

Все три поверхности (`/`, `/book`, `/admin`) обязаны соответствовать **WCAG 2.2
уровня AA** — это декларируемый набор проверяемых критериев, а не сертификация:
отдельного аудита и «сертификата» не делаем. 2.2 выбран вместо 2.1, потому что
включает его целиком, а добавленные критерии для нашего UI почти бесплатны
(target size 24×24, focus not obscured, отсутствие drag-only взаимодействий).
Решения ниже связывают реализацию `/book` (ADR-0011) и `/admin` (ADR-0012); сами
экраны идут отдельными тикетами.

## Как проверяем

- **Автоматически:** `axe-core` через **jest-axe** (`toHaveNoViolations`,
  подключается `expect.extend`; работает на vitest 5) в компонентных тестах
  фронтенда (#15), для каждого экрана и его состояний, с тегами
  `wcag2a/wcag2aa/wcag21aa/wcag22aa`. Тонкий хелпер — `frontend/test/helpers/a11y.ts`.
- **Вручную:** чеклист клавиатуры в спецификации `#2` — фокус-порядок, стрелки,
  Escape, возврат фокуса, анонсы.
- **Контраст — только вручную.** В `jsdom` нет layout, поэтому axe правило
  `color-contrast` не выполняет; контраст проверяем глазами/инструментом по
  палитре Mantine, автоматический ассерт его не покрывает.

## Адаптивность

- **Поддерживаемая ширина — от 320px**, mobile-first. Отзывчивость — только через
  Mantine-пропсы (`SimpleGrid`, `Grid.Col`), без собственных media queries и `.css`;
  граница «десктоп» — `sm` (48em/768px).
- **Полоса дат (`/book`) — всегда 7 колонок**, то есть две строки по 7 на любой
  ширине. На узких экранах ячейка мельче (число + короткий день недели, метка
  «сегодня» остаётся только цветом/точкой), но весь горизонт виден сразу — ради
  этого полоса и выбрана в ADR-0011.
- **Сетка слотов (`/book`)** — `cols={{ base: 3, sm: 4 }}`, как в прототипе; кнопки
  `HH:MM` остаются крупными тап-таргетами.
- **`/admin` на узких** — рельс типов и лента встреч **в столбец** (рельс сверху на
  всю ширину, лента под ним); выдвижная панель на узких — **на всю ширину**
  (`size: 100%`), на десктопе `md`.

## Клавиатура и фокус

- **Полоса дат** — семантика одиночного выбора: `role="radiogroup"` +
  `role="radio"` + **roving tabindex**, стрелки ←→↑↓ по 2D-раскладке, Enter/Space —
  выбор. Обычные кнопки с `aria-pressed` отброшены: 14 Tab-стопов утомительны.
- **Сетка слотов** — нативные `<button>`; занятые и начавшиеся — `disabled`,
  поэтому Tab их пропускает нативно; roving tabindex и стрелки не вводим (сетка
  короткая, Tab предсказуем).
- **Мастер `/book`** — при «Далее»/«Назад» фокус переезжает на **заголовок нового
  шага**, и шаг анонсируется; `Stepper` — только индикатор, недостигнутые шаги не
  фокусируемы.
- **Выдвижная панель `/admin`** — встроенный focus-trap Mantine `Drawer`
  (`role="dialog"`, `aria-modal`, возврат фокуса) плюс Escape закрывает, начальный
  фокус — на первом поле, кнопка-триггер получает `aria-expanded`/`aria-controls`.
- **Анонсы асинхронных состояний** — live-регион `role="status"`/`aria-live="polite"`
  для смены «загрузка → загружено», пустого дня и конфликта на шаге подтверждения;
  блокирующая ошибка чтения с «Повторить» — `role="alert"` (assertive).
- **Доступные имена групп** — полоса дат («Дата, окно записи — 14 дней»), сетка
  слотов с выбранной датой («Слоты на 12 октября»), в `/admin` — «Типы событий»
  (рельс) и «Предстоящие встречи» (лента) как видимые заголовки.

## Baseline-гигиена

- Выбранные дата/слот — `aria-pressed` (дата — `aria-current="date"`);
  «занято/началось» передаётся нативным `disabled`, отдельного текста не добавляем.
- Видимое фокус-кольцо (дефолт Mantine), контраст AA, уважаем
  `prefers-reduced-motion`.
- Один `h1` на экран, landmarks (`header`/`main`/`nav`), skip-link «К содержимому»,
  `document.title` на маршрут, `lang="ru"` на `<html>`.

## Considered Options

- **WCAG 2.1 AA** — отброшено: 2.2 включает 2.1 и добавляет критерии, которые нам
  ничего не стоят; брать заведомо устаревшую редакцию смысла нет.
- **Прагматичный минимум без уровня** — отброшено: без названного уровня нечего
  проверять и нечем закрывать спор «это баг или нет».
- **`vitest-axe` вместо `jest-axe`** — отброшено: пакет на 0.1.0, `jest-axe` 11
  зрелее и совместим с vitest через `expect.extend`.
- **Полоса дат: обёртка по 3–4 в ряд или горизонтальный скролл** — отброшено:
  обёртка растёт в высоту, скролл прячет часть горизонта; обе ломают смысл «весь
  горизонт виден сразу».
- **Дата: обычные кнопки с `aria-pressed`** — отброшено (см. выше).
- **Слоты: roving tabindex и стрелки** — отброшено: для короткой сетки кнопок
  нативный Tab предсказуемее и проще.

## Consequences

- Компонентные тесты #15 дополняются axe-ассертами через общий хелпер; axe **не**
  ловит контраст в `jsdom`, поэтому контраст остаётся на ручной чеклист.
- Критерий 2.2 target size 24×24 ограничивает минимальный тап-таргет полосы дат на
  320px — при вёрстке это проверяется вместе с Q4-раскладкой (7 колонок).
- ADR-0011 и ADR-0012 уточняются в части раскладки: полоса дат — 7 колонок на всех
  ширинах; панель `/admin` — full-width на узких.
- Реализация `/book` и `/admin` по этому каркасу пойдёт отдельными тикетами.
